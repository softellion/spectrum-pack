# Changelog

Notable user-facing changes to Spectrum. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0]

### Added

- Application UI\UX design improvements.
- UI translation in English and Russian.
- Scene outliner, transform gizmo, and object properties panel.
- Arithmetic expressions in numeric fields.
- Built-in help (F1) in English and Russian.

## [0.1]

### Added

- Initial release of the Spectrum rendering application.
- KOMPAS-3D plugin for one-click export of the current assembly.
- Path-traced rendering on AMD Radeon ProRender with an interactive viewport.
- Material library from AMD GPUOpen with search and category filter.
- Custom material files (`.mtlx`, MaterialX).
- Image-based lighting (HDR environment).
