## Возможности

- **Интеграция с КОМПАС-3D.** Плагин экспортирует текущую сборку, и сцена появляется в Spectrum автоматически.
- **Рендеринг на GPU.** Трассировка лучей для получения изображения максимального качества.
- **Библиотека материалов.** Материалы AMD GPUOpen с поиском, фильтром по категориям и автоматической загрузкой при применении.
- **Собственные материалы.** Поддержка файлов `.mtlx` (MaterialX) — добавляйте свои материалы через диалог загрузки.
- **Освещение по изображению (IBL).** Встроенное окружение можно заменить HDR-панорамой — меняются и свет, и отражения.
- **Редактирование сцены.** Дерево объектов из КОМПАС-3D, гизмо трансформаций (перенос / поворот / масштаб), панель свойств выделенного объекта.
- **Пресеты качества.** Настройки рендера сгруппированы по вкладкам с пресетами; изменения сохраняются автоматически и применяются к активному рендеру.

## Системные требования

| Компонент | Требование |
|-----------|------------|
| ОС | Windows 10/11 (x64) |
| GPU | AMD или NVIDIA, актуальные драйверы |
| CAD | КОМПАС-3D **v23 или новее** (для экспорта моделей) |
| Интернет | нужен для загрузки материалов из библиотеки AMD GPUOpen |
| Диск | папка установки с правами на запись (материалы загружаются рядом с программой) |

## Установка

Установщика нет — дистрибутив распространяется как архив (portable версия).

1. **Распакуйте архив.** Скачайте `spectrum_vX.Y.zip` со страницы [Releases](../../releases) и распакуйте в папку с правами на запись, например `C:\Users\<user>\Spectrum`.
2. **Подключите плагин в КОМПАС-3D.** Откройте меню «Приложения» и укажите путь к `spectrum.kompas3d.rtw` из распакованной папки — плагин поставляется одним файлом.
3. **Запустите Spectrum.** Выполните `spectrum.exe`. Spectrum должен быть запущен до экспорта из КОМПАС-3D — иначе плагин сообщит, что программа недоступна.

## Первый рендер

1. **Импортируйте модель.** Командой плагина Spectrum в КОМПАС-3D экспортируйте текущую сборку — сцена появится в Spectrum автоматически.
2. **Постройте кадр.** Вращайте и панорамируйте камеру, пока модель не займет нужное положение.
3. **Примените материалы.** Выделите объекты (щёлчок в вьюпорте или в дереве сцены) и примените материал из библиотеки.
5. **Сохраните результат.** Правый клик → **Save rendered image**.

Полная справка доступна в самом приложении: клавиша **F1**.

## Управление камерой и выделением

| Действие | Управление |
|----------|------------|
| Выделить объект | левый клик |
| Добавить к выделению | Ctrl + левый клик |
| Движение камеры | средняя кнопка + перетаскивание |
| Вращение камерой | правая кнопка + перетаскивание |
| Зум | колесо мыши |
| Контекстное меню | правый клик без перетаскивания |

Гизмо трансформаций появляется при выделении одного объекта; режимы: **T** — перенос, **R** — поворот, **S** — масштаб. Полный список горячих клавиш — во встроенной справке (F1).

## Известные ограничения

- **Состояние приложения не сохраняется между запусками.** При закрытии Spectrum сцена и примененные изменения сбрасываются, сборку из КОМПАС-3D нужно будет экспортировать заново.

## Частые вопросы и проблемы

**Windows SmartScreen или антивирус предупреждает о spectrum.exe.**
Исполняемый файл не имеет цифровой подписи, поэтому Windows может показать предупреждение. Нажмите «Подробнее» → «Выполнить в любом случае». Скачивайте архив только с официальной страницы [Releases](../../releases) этого репозитория.

**Плагин сообщает, что Spectrum недоступен.**
Запустите `spectrum.exe` до экспорта из КОМПАС-3D — плагин подключается только к работающему экземпляру программы.

**Библиотека материалов не загружается.**
Библиотека загружается из AMD GPUOpen и требует подключения к интернету (доступ к `api.matlib.gpuopen.com`). Панель покажет ошибку сети с кнопкой повтора; загрузка также возобновится автоматически после восстановления соединения.

**Рендер не запускается, чёрный вьюпорт или низкая производительность.**
Убедитесь, что установлен GPU AMD Radeon или NVIDIA, и обновите драйверы видеокарты.

Другие вопросы — во встроенной справке (**F1**) или [напишите нам](#поддержка).

## Работа с сетью

Spectrum обращается к интернету только для загрузки материалов AMD GPUOpen (`api.matlib.gpuopen.com`, `images.matlib.gpuopen.com`) и открытия ссылок из встроенной справки в браузере. Телеметрия не собирается.

## Удаление

1. Отключите плагин в КОМПАС-3D (меню «Приложения»).
2. Удалите распакованную папку — загруженные материалы и кэш хранятся внутри неё, следов в системе не остаётся.
